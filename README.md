# Irfan Shahzad — Portfolio

Engineering Manager portfolio for SaaS, fintech, and AI product work.

## Stack

- React 18 + Vite
- Tailwind CSS
- Framer Motion
- Formspree (contact)

## Run locally

```bash
npm install
npm run dev
```

## Customize

Edit content in `src/constants/index.js`:

- `socials` — LinkedIn, GitHub, resume URLs
- `projects` — case studies
- `recommendations` — LinkedIn recommendation quotes
- `certificates` — HackerRank verify links and badge images

Set `VITE_FORMSPREE_FORM_ID` in `.env` for the contact form.
